# BMS Telemetry Visualizer

A battery telemetry pipeline built with Polars and Plotly to parse and visualize pack voltage, current, and State of Charge (SoC) time-series data.

## Prerequisites

Ensure you have [uv](https://docs.astral.sh/uv/) installed.

## Execution Commands

### 1. Install Dependencies
Sync your virtual environment and install all required packages:

```bash
uv sync
```

### 2. Run the app

```bash
uv run bms-visualizer
```
